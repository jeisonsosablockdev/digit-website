# Initial Next.js Landing Stitch Import

Last Updated: 2026-05-12 UTC

## Summary

Se monto la primera app web SSR en Next.js App Router usando como referencia directa el export de Stitch entregado por el usuario.

## Included

- estructura App Router en `app/`
- setup de Tailwind y PostCSS
- layout SSR con tipografias de Next Font
- landing inicial con hero, capas, dashboard preview, FAQ, footer y bottom nav
- limpieza de hacks del export original de Stitch

## Notes

- El look se preserva con minima reinterpretacion.
- La fase inicial no incluye autenticacion ni interacciones de producto reales.
